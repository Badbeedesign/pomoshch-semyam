ДЕМОВЕРСИЯ ГЛАВНОЙ СТРАНИЦЫ

Загрузите содержимое этой папки (index.html, styles.css, script.js и папку assets) в корень репозитория GitHub.
Settings → Pages → Deploy from a branch → main → / (root).

ВАЖНО: это первая версия главной страницы для утверждения дизайна. Заявки пока не собираются; ссылка на PDF пока не подключена. До публичного запуска нужно подготовить и проверить юридические документы, персональные данные и сведения об услугах.


ОБНОВЛЕНИЕ: Добавлены четыре тематические фотографии (первый экран, документы, городская архитектура, психологическая помощь).
ВНИМАНИЕ: дополнительные фотографии подгружаются по HTTPS с images.unsplash.com и требуют интернета; они не входят в архив как локальные файлы. Перед публичным запуском проверьте доступность, содержание и условия использования изображений, при необходимости замените их своими лицензированными фото. Фотография Анастасии по-прежнему находится локально в assets/anastasia.jpg.
